# 🚀 Make Your Portfolio LIVE (2 Minutes)

## Step 1: Enable GitHub Pages

1. **Click this link**: 
   👉 https://github.com/Abhishek-UIUX/Portfolio/settings/pages

2. **Under "Build and deployment"**:
   - Find **"Source"** dropdown
   - Change from **"Deploy from a branch"** to **"GitHub Actions"**
   - It will save automatically

## Step 2: Watch Deployment

1. **Go to Actions tab**:
   👉 https://github.com/Abhishek-UIUX/Portfolio/actions

2. You should see **"Deploy to GitHub Pages"** workflow running
   - If not, click **"Run workflow"** button
   - Select **"main"** branch
   - Click **"Run workflow"**

3. **Wait 2-3 minutes** for deployment to complete
   - Green checkmark ✅ = Success!
   - Red X ❌ = Check error logs

## Step 3: Visit Your Live Site! 🎉

Once deployment is complete, your portfolio will be live at:

### 🌐 **https://abhishek-uiux.github.io/Portfolio/**

## Troubleshooting

### If you see 404 error:
1. Wait 5 more minutes (DNS propagation)
2. Check Settings → Pages shows the correct URL
3. Verify GitHub Actions workflow completed successfully

### If deployment fails:
1. Go to Actions tab
2. Click on the failed workflow
3. Check error logs
4. Common fix: Re-run the workflow

### If themes don't work:
1. Hard refresh: `Cmd + Shift + R` (Mac) or `Ctrl + Shift + R` (Windows)
2. Clear browser cache
3. Try incognito/private mode
