# Professional Design System Documentation

## Color Theory & Semantic Naming

This theme system follows professional UI/UX design principles with **semantic color roles** rather than arbitrary assignments.

## Color Role Definitions

### 1. **Background** (Darkest in Dark Mode)
- **Purpose**: Main page background, foundational layer
- **Characteristics**: Deep, rich tones that don't strain the eyes
- **Usage**: Body background, main container backgrounds
- **Contrast**: Lowest luminosity in dark mode, highest in light mode

### 2. **Surface** (Elevated Elements)
- **Purpose**: Cards, panels, elevated UI components
- **Characteristics**: Slightly lighter than background, creates depth
- **Usage**: Card backgrounds, modal dialogs, dropdown menus
- **Contrast**: Mid-range luminosity, provides layering

### 3. **Primary** (Main Interactive Color)
- **Purpose**: Primary actions, CTAs, interactive elements
- **Characteristics**: High visibility, accessible, brand-defining
- **Usage**: Buttons, links, active states, focus indicators
- **Contrast**: Must meet WCAG AA standards against background

### 4. **Secondary** (Supporting Actions)
- **Purpose**: Secondary actions, less prominent interactions
- **Characteristics**: Complementary to primary, less dominant
- **Usage**: Secondary buttons, tags, badges, subtle highlights
- **Contrast**: Balanced visibility without competing with primary

### 5. **Accent** (Text & Highlights)
- **Purpose**: Text content, borders, subtle accents
- **Characteristics**: High contrast for readability
- **Usage**: Body text, headings, borders, icons
- **Contrast**: Maximum readability against background

## Design Principles Applied

### 1. **60-30-10 Rule**
- **60%**: Background (dominant color)
- **30%**: Surface (secondary color)
- **10%**: Primary + Secondary (accent colors)

### 2. **Contrast Ratios**
All themes maintain WCAG AA standards:
- **Normal text**: Minimum 4.5:1 contrast ratio
- **Large text**: Minimum 3:1 contrast ratio
- **Interactive elements**: Clear visual distinction

### 3. **Color Psychology**
Each theme is designed for specific emotional responses:
- **Warm colors** (reds, oranges): Energy, passion, urgency
- **Cool colors** (blues, greens): Trust, calm, professionalism
- **Neutral colors** (grays): Balance, sophistication, modernity

### 4. **Semantic Naming**
Colors are named by their **function**, not appearance:
- ❌ Bad: `color1`, `color2`, `darkBlue`
- ✅ Good: `background`, `surface`, `primary`

### 5. **Mode Adaptation**
Each theme intelligently adapts to dark/light mode:
- **Dark mode**: Uses colors as designed
- **Light mode**: Inverts hierarchy (accent becomes background)

## Adding Custom Themes

Follow this professional process:

### 1. Choose Your Base
Start with the darkest color for background (dark mode)

### 2. Build Hierarchy
- Surface: 10-20% lighter than background
- Primary: High contrast, brand color
- Secondary: Complementary to primary
- Accent: Highest contrast for text

### 3. Test Contrast
Use tools like:
- WebAIM Contrast Checker
- Coolors.co contrast checker
- Browser DevTools accessibility panel

### 4. Validate Psychology
Ensure colors match intended emotional response

### 5. Test Both Modes
Verify theme works in dark AND light mode

## Color Accessibility Guidelines

### Minimum Contrast Ratios (WCAG AA)
- **Body text** (< 18pt): 4.5:1
- **Large text** (≥ 18pt): 3.0:1
- **UI components**: 3.0:1
- **Graphical objects**: 3.0:1

### Best Practices
✅ Test with color blindness simulators
✅ Don't rely on color alone for information
✅ Provide text labels for interactive elements
✅ Use patterns/icons in addition to color
✅ Test in both dark and light modes
